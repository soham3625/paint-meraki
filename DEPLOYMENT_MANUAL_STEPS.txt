This document provides exact, step-by-step instructions for the 3 manual setup

STEP 1: ROTATE EXPOSED RESEND API KEY
--------------------------------------------------------------------------------
Why: The previous Resend key was exposed in a template file. Generating a new key
ensures no unauthorized person can send emails through your account.

1. Open your browser and log into:
   https://resend.com/login

2. Go to the API Keys section:
   https://resend.com/api-keys

3. Locate the existing key that begins with "re_5aqNg6JF...":
   - Click the three dots (...) next to it.
   - Click "Delete" or "Revoke".

4. Click the "Create API Key" button (top-right corner):
   - Name: Paint Meraki Production
   - Permission: Full access (or Sending access)
   - Domain: All domains (or your verified domain)
   - Click "Add"

5. COPY THE NEW KEY IMMEDIATELY:
   - It will look like: re_xxxxxxxxxxxxxxxxxxxxxxxx
   - Resend only displays this key once!

6. Where to put this new key:
   - On your computer: Open your local file:
     d:\aastha patel\paint-meraki\.env.local
     Update or add the line:
     RESEND_API_KEY="re_your_new_key_here"

   - In Hosting (Vercel): You will paste this same key in Step 3.


--------------------------------------------------------------------------------
STEP 2: ADD YOUR LIVE DOMAIN TO FIREBASE AUTHORIZED DOMAINS
--------------------------------------------------------------------------------
Why: Firebase Phone OTP Authentication (SMS delivery and reCAPTCHA) is restricted
to authorized domains. By default, only "localhost" is enabled. When your website
is hosted on Vercel, Firebase will reject OTP requests with an auth/unauthorized-domain
error unless your domain "paintnmeraki.vercel.app" is added to this whitelist.

1. Open Google Firebase Console:
   https://console.firebase.google.com/

2. Select your project:
   paintmeraki-1b0bd

3. In the left navigation menu:
   Click "Build" -> "Authentication"

4. At the top of the Authentication screen:
   Click the "Settings" tab.

5. In the left sub-menu under Settings:
   Click "Authorized domains"
   Direct link: https://console.firebase.google.com/project/paintmeraki-1b0bd/authentication/settings

6. Click the "Add domain" button:
   - Enter your live domain WITHOUT "https://" and WITHOUT trailing slashes:
     
     paintnmeraki.vercel.app

   - (If you later add a custom domain e.g. paintmeraki.com, also add it here)

7. Click "Done" / "Save".


--------------------------------------------------------------------------------
STEP 3: INPUT ENVIRONMENT VARIABLES INTO VERCEL SETTINGS
--------------------------------------------------------------------------------
Why: Because secret files like .env.local are excluded from Git for security,
Vercel runs your app in a secure cloud container and needs these values
configured in its Project Settings.

1. Go to your Vercel Dashboard:
   https://vercel.com/dashboard

2. Click on your "paint-meraki" project.
3. Click "Settings" (top navigation bar).
4. Click "Environment Variables" in the left sidebar.
5. Add each KEY and VALUE from the list below.
   Ensure "Production", "Preview", and "Development" checkboxes are selected.
6. Click "Save".
